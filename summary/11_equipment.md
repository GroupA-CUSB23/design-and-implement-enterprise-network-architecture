## 🔍 ប្រភេទឧបករណ៍ សំខាន់ៗ

### 🔹 Router
- **មុខងារ**: បញ្ជូន Packet រវាងបណ្តាញ (Networks)
- **Layer**: Layer 3 (Internet Layer)
- **ឧទាហរណ៍**: Cisco 2911, 1941

### 🔹 Switch
- **មុខងារ**: ភ្ជាប់ Device ក្នុងបណ្តាញតែមួយ
- **Layer**: Layer 2 (Data Link)
- **Feature**: VLAN, MAC Table
- **ឧទាហរណ៍**: Cisco 2960, 3560

### 🔹 Firewall
- **មុខងារ**: ការពារពីការវាយប្រហារ Internet
- **Filter**: Source IP, Destination Port, Protocol
- **ឧទាហរណ៍**: Cisco ASA, pfSense

### 🔹 Access Point (AP)
- **មុខងារ**: Wi-Fi Coverage
- **Standard**: 802.11ac (Wi-Fi 5) ឬ 802.11ax (Wi-Fi 6)

### 🔹 Server
- **មុខងារ**: ផ្ដល់សេវាកម្ម (File, Web, Email)
- **OS**: Windows Server, Linux (Ubuntu/CentOS)
